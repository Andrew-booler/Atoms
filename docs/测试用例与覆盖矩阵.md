版本：3.1｜日期：2026-10-31｜配套：《测试策略与规范》

> 仅单元与集成两层。当前目标已接入代码，真实执行证据见[测试执行记录](测试执行记录.md)，不将同编号测试通过等同于历史设计全部子条件通过。

## 阅读背景与必要概念

本文是 Atoms Studio 测试的跨模块索引，说明固定数据、控件、场景和接口如何关联。使用者提交需求、确认计划、构建并预览保存的 HTML 文档，也可恢复历史版本。HTML 是浏览器呈现页面的文字格式；本阶段目标为共享账号和数据、串行操作及模拟 AI 输出。现有代码尚未全部符合目标，下面的映射不是测试通过证据。

项目保存工作空间状态，消息保存需求、计划或备注，历史版本保存完整 HTML。id 是记录标识，version_no 是项目内版本序号，current_version 保存项目当前使用的版本序号；固定数据中的 101、201、202 是示例标识，其来源和关系见下表。

单元测试只检查一个类或页面并替换全部外部调用；集成测试组合真实页面、业务接口和专用数据库，仅 AI 输出用 mock（预置结果或受控失败）替代，不评估生成质量。HTTP 是网络协议，SDK 是前端请求封装，API 是接口约定。GET 读取、POST 提交、DELETE 删除；200/201 成功，404 资源不存在或版本不属于项目，422 必要字段无效，502 提供者明确失败。

requirement 表示本轮需求，plan_summary 表示整理后的计划文本，outline 表示页面结构，artifact_html 表示完整 HTML，profile 表示提供者配置键。计划字段 summary 是摘要、stack 是技术说明、steps 是步骤数组（title 为标题、detail 为说明）、files 是文件数组（path 为路径、purpose 为用途）；结构字段 title 是页面标题、sections 是区域数组（name 为区域名、blocks 为内容）、interactions 是交互说明、seed_data 是初始数据。消息 role 是发言方、kind 是消息类型、content 是正文、meta 是附加信息；created_at 与 updated_at 分别是创建及更新时间。

计划卡展示计划并提供确认、调整和复制；iframe 是嵌入预览容器，srcDoc 是传入 HTML 的属性，Blob 是外开预览的临时内容，抽屉是从边缘展开收起的面板（手机已提供项目抽屉）。


## 1. 约定与固定数据

### 预期依据

- **新目标**：本轮确认的共享账号、串行操作、AI输出预置模拟响应，以及确定性传递、展示、保存、读取和预览。
- **当前代码**：静态代码显示的行为，仅做明确特征记录，不视作符合新目标。
- **待确认**：用户尚未指定的恢复、长度、状态或入口规则。不能擅自设为已批准验收要求。

所有单元用例的前置条件均为：只挂载指定页面或实例化指定职责对象，网络、SDK、数据库、AI提供者、存储、剪贴板、窗口和时钟等外部调用全部mock；“请求”列表示mock调用记录，不发生真实网络或写库。

所有集成用例的前置条件均为：专用环境中的共享数据上下文已接入，实际前端、SDK、Studio后端和测试数据库可用，AI边界已替换为模拟提供者。按顺序执行；前一操作成功或失败结束后才执行下一操作。本轮已建立上述条件；默认使用mock，不能调用旧真实AI服务作为模拟测试。

HTTP路径在每例中明确列出。计划接口成功响应含 plan（计划）、message（已保存消息）、model（提供者标识）；结构接口成功响应含 outline（结构）、model；构建接口成功响应含 project（项目摘要）、version（新增历史版本）、message（构建消息）、outline_title（结构标题）、artifact_html（完整 HTML）。消息含id、role、kind、content、meta、created_at；项目摘要含id、name、description、status、current_version、preview_ready、version_count、updated_at。

失败必须检查未调用下游、操作结束以及数据库实际结果，不能仅检查错误提示。预置模拟响应不用于评估生成工程、语义或需求满足程度。

## 7. 术语表

- 单元测试：测试一个组件、类或页面，所有外部调用均mock。
- 集成测试：组合实际模块、SDK、业务接口与测试数据库；AI边界使用预置模拟输出。
- mock：用固定成功结果或受控错误替换外部调用，记录输入和调用次数。
- 示例提示按钮（旧称示例芯片）：点击将一条示例文字填入需求框，不自动提交。
- 计划卡：显示计划摘要、步骤和文件说明，并提供确认、调整、复制的区域。
- 抽屉：从边缘展开并可收起的面板；手机已提供项目抽屉。
- profile：提供者配置键，保留接口技术字段，不表示本阶段真实调用模型。
- JSON：接口中对象和数组的组织格式。
- HTML：完整预览文档文本；本阶段为预置数据，不是本轮生成的工程。
- iframe / srcDoc：嵌入工作台的预览容器及传入HTML的属性。
- Blob：用于外开预览的浏览器临时内容，不是稳定发布地址。
- 快照与项目当前使用的版本序号：快照保存完整版本HTML；current_version 保存项目当前使用的版本序号，决定展示哪一版。
- 串行：一项操作和其子请求结束后才开始下一项，不同时执行多个业务操作。
- 持久化：数据库保存后可重新读取，不等同于仅在页面上显示。
- SDK：前端业务接口调用封装。
- HTTP状态码：200/201成功，404资源不存在或版本不属于项目，422必要字段无效，502提供者明确失败。
- 键盘焦点：键盘当前正在操作的控件位置，应可见并可移动。
- 单元挂载：用 jsdom + React Testing Library 挂载实际组件，执行点击、键盘与替身回调；类单元使用受控Promise。
