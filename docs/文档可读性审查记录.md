## 4. 代表性修改

旧：恢复成功后页头可能仍旧，重试只清错。
新：恢复摘要立即同步页头/侧栏，清空旧预览；后续读取失败提示已恢复，重试只读取。
旧：批准只在本地，确认可能再次保存。
新：计划meta.approved/version_id与版本、构建消息、项目序号同事务写入；同计划重复请求返回已有版本。
旧：长需求截断，手机无项目入口。
新：完整需求传递；最小抽屉提供项目打开与关闭。
