# 正式文档索引

版本：3.1｜日期：2026-10-31

## 适用范围与阅读背景

本索引用于查找 Atoms Studio 的有效项目文档。工作台让使用者提交文字需求、查看计划、确认构建、预览保存的 HTML 页面，并恢复历史版本。HTML 是浏览器显示页面的文档文字；历史版本保存每次构建得到的完整文档。

本阶段目标是所有使用者共享同一账号及项目数据，每项操作成功或失败结束后再开始下一项（串行操作）。AI 输出由模拟提供者返回预置结果，称为 mock；未来真实 AI 只保留替换边界，不评估输出质量。当前Studio路径已接入共享路由、默认mock及统一串行状态。

每篇正式文档均应可独立阅读；下面的顺序只是查阅建议，不是理解其他文档的前提。单元测试只检查一个类或页面并替换全部外部调用；集成测试检查真实模块、接口和数据库协作，仅 AI 输出仍模拟。测试执行结果独立登记，不设Mike或其他角色的强制审阅门禁。

## 交付边界与缺项

保留React/Vite、Python/FastAPI/Atoms Cloud。共享数据、模拟提供者、串行操作、确认持久化、重试与恢复反馈已经接入；不改生产表结构，不调用真实AI，不收集密钥。仅提取实际需要的职责，不创建形式化控制器/仓储全集。

[测试执行记录](测试执行记录.md)维护真实命令、七模块通过/失败/未执行和未覆盖子情景。自动化56个测试不代表历史设计每个子条件均通过。列表容量不扩展，草稿刷新不保证；不新增发布或Cloud管理。

模块篇幅表为上一文档阶段估算，不是本次修改后的打印验证；本轮不输出PDF、不承诺真实页数。

## 术语表

- 设计映射：已建立需求、场景、控件及用例关联，不是执行覆盖率。
- MVC：模型、视图与控制器的职责分离，不要求React使用类组件。
- mock：预置输出与受控失败代替外部能力。
- 许可核实：确认来源授权文本及适用范围；网络失败不等于获得复制许可。
