# 正式文档索引

版本：3.3｜日期：2026-11-04

## 适用范围与阅读背景

本索引用于查找 Atoms Studio 的有效项目文档。工作台让使用者提交文字需求、查看计划、确认构建、预览保存的 HTML 页面，并恢复历史版本。HTML 是浏览器显示页面的文档文字；历史版本保存每次构建得到的完整文档。

本阶段目标是所有使用者共享同一账号及项目数据，每项操作成功或失败结束后再开始下一项（串行操作）。AI 输出由真实供应商返回（阿里百炼主选、Ark/智谱备选），四种示例输入短路返回预置结果，供应商不可用时回退 mock；测试中 AI 边界仍用 mock 替代。登录认证与多用户数据隔离已决策为 Phase 17，实施前不承诺账号级隔离。当前Studio路径已接入共享路由、真实 AI 与统一串行状态；错误响应统一契约（Phase 16）尚未实施。

每篇正式文档均应可独立阅读；下面的顺序只是查阅建议，不是理解其他文档的前提。单元测试只检查一个类、组件或页面并替换全部外部调用；集成测试检查真实模块、接口和数据库协作，仅 AI 输出仍模拟。测试执行结果独立登记，不设Mike或其他角色的强制审阅门禁。

## 术语表

- 设计映射：已建立需求、场景、控件及用例关联，不是执行覆盖率。
- MVC：模型、视图与控制器的职责分离，不要求React使用类组件。
- mock：预置输出与受控失败代替外部能力。
- 许可核实：确认来源授权文本及适用范围；网络失败不等于获得复制许可。
